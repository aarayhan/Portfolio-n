# 00 MASTER RULES

Aturan utama untuk siapa pun (manusia atau AI) yang mengerjakan project ini. Baca file ini dulu.

## Aturan keras
1. **Keputusan UI harus disetujui Raey dulu.** Jangan ubah layout, warna, font, atau gaya visual tanpa jawaban dari Raey. Tulis opsi dan tanya.
2. **Jangan salin konten atau aset dari situs orang lain.** Referensi hanya untuk pola, bukan teks atau gambar.
3. **Jangan ada rahasia di repo.** Token, API key, password: tidak boleh masuk file atau chat.
4. **Semua teks placeholder harus ditandai.** Lokasi data: `src/lib/site.ts`.
5. **Catat setiap keputusan** di `17_DECISIONS.md` dan setiap perubahan di `16_CHANGELOG.md`.
6. **Update `15_MICROTASKS.md`** saat mulai dan selesai satu tugas.

## Cara kerja
- Bahasa komunikasi: Indonesia. Kode dan nama file: Inggris.
- Singkat dan langsung. Kritik ide yang lemah secara objektif.
- Tanya maksimal 2 pertanyaan tajam kalau ambigu. Jangan menebak.
- Satu langkah, lalu tunjukkan hasil. Jangan bangun semua section sekaligus.
- Verifikasi sebelum klaim selesai: build lolos, cek desktop dan mobile.
